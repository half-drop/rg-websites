# 云滴 YUNDI — 云中藏雨

原创甜品的品牌与产品网站原型。所有产品图均为 SVG/CSS 结构概念示意，产品仍处于配方设计阶段，未经过实际试制，暂未开售。

## 访问

https://half-drop.github.io/rg-websites/yundi/

## 实现

- 单文件 `index.html`，无构建依赖、第三方脚本、外部字体或跟踪代码。
- 响应式布局、三种风味预览、剖面切换、三颗/六颗搭配清单。
- 复制功能无法使用时，提供可手动复制的对话框。
- 不提供下单、支付或个人信息收集。
- `scripts/build-pages.mjs` 将本目录复制至 `_site/yundi/`，原有两个 Wiki 和总入口保持不变。
